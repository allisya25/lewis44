# SPPE Workshop Hub — MPC Workshop Management System (Prototype)

Internal prototype for Seksyen Prestasi Produktiviti dan Ekonomi (SPPE), Malaysia Productivity Corporation.

## Run
Open `index.html` in a browser, or enable **GitHub Pages** (Settings → Pages → Deploy from branch → `main` / root).

## Notes
- Outside claude.ai the system runs in **offline demo mode**: data is saved in each person's own browser only, and there is no staff login or shared database.
- The live shared version (shared database, real roles, Outlook import) runs at the claude.ai artifact link.
- Libraries in `vendor/`: SheetJS (xlsx), jsPDF, jsPDF-AutoTable.
